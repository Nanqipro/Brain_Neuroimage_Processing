## 一、Baseline自适应改进

### 1.1 新增功能

#### ✨ 三种baseline估计方法

| 方法 | 描述 | 适用场景 |
|------|------|---------|
| `'global'` | 全局固定baseline（原有方法） | 基线稳定的短时间记录 |
| `'sliding'` | 滑动窗口baseline（新增） | 有基线漂移的长时间记录 |
| `'auto'` | 自动选择（新增） | 自动评估数据特性并选择最佳方法 |

#### 📝 新增辅助函数

```python
# 1. 滑动窗口baseline估计
estimate_sliding_baseline(data, window_size=None, percentile=8, fs=4.8)

# 2. 自动选择baseline方法
auto_select_baseline_method(data, fs=4.8, noise_threshold=2.0)
```

### 1.2 核心改进点

#### ✅ **智能baseline估计**
```python
# 自动检测基线漂移
drift_ratio = baseline_drift / noise_level

if drift_ratio < 2.0:
    方法 = 'global'  # 基线稳定
elif drift_ratio < 5.0:
    方法 = 'sliding'  # 中等漂移
else:
    方法 = 'sliding'  # 严重漂移，使用小窗口
```

#### ✅ **局部baseline跟踪**
- 每个钙波使用其**峰值处的局部baseline**计算振幅
- 边界查找使用**位置相关的baseline数组**
- AUC计算使用**区间内的局部baseline**

#### ✅ **向后兼容**
- 默认使用`'global'`方法，保持原有行为
- 只在需要时启用新功能

### 1.3 使用方法

```python

# 方法2: 使用滑动baseline

)
```

### 1.4 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `baseline_method` | str | `'global'` | baseline方法：`'global'` 或 `'sliding'` |
| `baseline_window_size` | int | `None` | 滑动窗口大小（采样点数），None时自动计算 |
| `baseline_auto_select` | bool | `False` | 是否自动选择baseline方法 |

## 二、复合峰（子峰）检测改进

### 2.1 问题分析

**原有子峰检测的不足**：
1. ❌ 仅基于prominence阈值，易误检
2. ❌ 边界定位不准确
3. ❌ 主峰上升/下降沿常被误判为子峰
4. ❌ 无质量评估机制

### 2.2 改进策略

#### ✨ 新增三个核心函数

```python
# 1. 查找显著波谷（用于子峰边界分割）
find_significant_valleys(data, start_idx, end_idx, min_depth_ratio=0.2)

# 2. 评估子峰质量
evaluate_subpeak_quality(smoothed_data, sp_idx, sp_start, sp_end, 
                        baseline, noise_level, fs=4.8, min_snr=2.0)

# 3. 改进的子峰检测（集成所有改进）
detect_subpeaks_advanced(smoothed_data, start_idx, end_idx, main_peak_idx, 
                        main_amplitude, baseline, noise_level, ...)
```

### 2.3 多级过滤机制

#### 📊 **7步检测流程**

```
步骤1: 初步峰值检测
    ├─ 自适应prominence阈值
    │   ├─ 方法1: 相对主峰 (prominence × main_amplitude)
    │   ├─ 方法2: 基于噪声 (2.0 × noise_level)
    │   └─ 取较大者，避免误检噪声
    └─ scipy.signal.find_peaks()

步骤2: 排除主峰禁区
    └─ 主峰前后至少5秒范围内不检测子峰

步骤3: 智能边界检测
    ├─ 寻找显著波谷作为边界
    └─ 无波谷时使用局部最小值

步骤4: 质量评估
    ├─ SNR检查 (min_snr ≥ 2.0)
    ├─ 持续时间检查 (0.5-20秒)
    ├─ 上升/衰减比例
    ├─ 单调性评估
    ├─ 衰减方向性
    └─ 综合质量评分 (0-1)

步骤5: 过滤低质量子峰
    └─ quality_score ≥ min_quality_score (默认0.30)

步骤6: 计算子峰特征
    ├─ amplitude, duration, fwhm
    ├─ rise_time, decay_time, auc
    ├─ snr, quality_score
    └─ rise_decay_ratio

步骤7: 按位置排序
```

#### ✅ **质量评分公式**

```python
quality_score = (
    0.30 × snr_score +          # SNR评分
    0.25 × rise_decay_score +   # 上升/衰减比例
    0.25 × monotonic_score +    # 单调性
    0.20 × decay_direction_score # 衰减方向性
)
```

## 八、技术细节

### 8.1 滑动baseline实现

**核心算法**：
```python
def estimate_sliding_baseline(data, window_size, percentile=8):
    baseline = np.zeros_like(data)
    half_window = window_size // 2
    
    for i in range(len(data)):
        start = max(0, i - half_window)
        end = min(len(data), i + half_window + 1)
        window_data = data[start:end]
        baseline[i] = np.percentile(window_data, percentile)
    
    # Savitzky-Golay平滑
    baseline = savgol_filter(baseline, smooth_window, 2)
    return baseline
```

**特点**：
- ✅ 逐点计算局部百分位数
- ✅ 平滑处理防止过度波动
- ✅ 边界自适应处理

### 8.2 质量评分实现

**评分权重**：
```python
quality_score = (
    0.30 × snr_score +          # 最重要：信噪比
    0.25 × rise_decay_score +   # 重要：形态特征
    0.25 × monotonic_score +    # 重要：单调性
    0.20 × decay_direction_score # 辅助：衰减方向
)
```

**阈值设计**：
