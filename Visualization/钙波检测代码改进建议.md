### ⚠️ 核心问题

根据调研报告**第III节末尾**的关键警告：

> "直接使用这些通用算法将导致严重低估真实的神经脉冲发放率。它们回答了'荧光峰值在哪里？'，却无法回答'神经脉冲在哪里？'。要解决后一个问题，必须使用反卷积。"  
> — 调研报告第III节："通用算法的分析陷阱"

**您的代码目前使用的是"通用峰值检测"方法**（Savitzky-Golay + `scipy.signal.find_peaks`），这意味着：

| 分析目标 | 适用性 | 说明 |
|---------|--------|------|
| **检测钙瞬变** (calcium transients) | ✅ 适合 | 可准确识别荧光信号的波峰 |
| **推断神经脉冲** (spike inference) | ❌ 不适合 | 高频脉冲会融合为单个钙瞬变 |

### 具体问题列表

1. **方法论边界不清晰**
   - 函数命名和注释混用"钙爆发"和"脉冲"概念
   - 未明确说明检测的是荧光峰值而非动作电位

2. **基线估计方法单一**
   - 仅使用固定百分位数（`baseline_percentile=8`）
   - 可能影响"波谷"（神经抑制）的检测
   - 调研报告第II节和第VII节强调基线方法的重要性

3. **缺少反卷积支持**
   - 如果科学目标是推断脉冲时序，当前方法不足
   - 调研报告第IV-V节详细介绍了OASIS、CASCADE等方法

4. **参数可复现性不足**
   - 未记录完整的分析元数据
   - 调研报告第IV节警告："参数即结论"（gOSI从0.91变为0.45）

5. **指示剂版本未适配**
   - 未根据GCaMP版本调整参数
   - 调研报告第V节："指示剂-算法协同进化"

```python
# 新增函数
def detect_with_oasis_deconvolution(data, fs=4.8, tau=1.5, optimize_tau=True):
    """
    使用OASIS算法进行钙信号反卷积，推断神经脉冲
    
    OASIS = Online Active Set method to Infer Spikes
    
    参数
    ----
    data : np.ndarray
        神经元荧光数据（ΔF/F）
    fs : float
        采样频率（Hz）
    tau : float
        钙指示剂衰减时间常数（秒）
        - GCaMP6f: ~0.4s
        - GCaMP6s: ~1.5s
        - GCaMP8: ~0.25s
    optimize_tau : bool
        是否自动优化tau参数
    
    返回
    ----
    spikes : np.ndarray
        推断的脉冲序列（稀疏）
    calcium_fitted : np.ndarray
        拟合的钙信号
    baseline : float
        估计的基线
    tau_estimated : float
        估计的衰减时间常数
    
    依赖
    ----
    需要安装CaImAn: pip install caiman
    """
    try:
        from caiman.source_extraction.cnmf.deconvolution import constrained_foopsi
    except ImportError:
        raise ImportError(
            "需要安装CaImAn库来使用OASIS反卷积。\n"
            "安装方法：pip install caiman\n"
            "或参考：https://caiman.readthedocs.io/"
        )
    
    # 标准化输入数据
    data_normalized = (data - np.min(data)) / (np.max(data) - np.min(data))
    
    # 运行OASIS反卷积
    # p: AR模型阶数（1=单指数衰减，2=双指数）
    # method: 'oasis' (快速在线), 'cvxpy' (精确但慢)
    # optimize_g: 是否优化衰减参数
    c, s, b, g, lam = constrained_foopsi(
        data_normalized,
        p=1,  # 单指数模型
        method='oasis',
        bas_nonneg=True,
        noise_range=[0.25, 0.5],
        noise_method='logmexp',
        optimize_g=int(optimize_tau),
        optimize_b=True
    )
    
    # 提取结果
    spikes = s  # 推断的脉冲强度
    calcium_fitted = c  # 反卷积后的钙信号
    baseline = b  # 基线
    tau_estimated = -1.0 / (fs * np.log(g[0])) if len(g) > 0 else tau
    
    # 检测脉冲事件（阈值法）
    spike_threshold = np.median(spikes[spikes > 0]) if np.any(spikes > 0) else 0
    spike_events = []
    spike_indices = np.where(spikes > spike_threshold)[0]
    
    for idx in spike_indices:
        spike_events.append({
            'spike_idx': idx,
            'spike_time': idx / fs,
            'spike_amplitude': spikes[idx],
            'calcium_value': calcium_fitted[idx]
        })
    
    return {
        'spikes': spikes,
        'spike_events': spike_events,
        'calcium_fitted': calcium_fitted,
        'baseline': baseline,
        'tau_estimated': tau_estimated,
        'method': 'OASIS',
        'parameters': {
            'tau_input': tau,
            'tau_optimized': tau_estimated,
            'optimize_tau': optimize_tau
        }
    }
```

```python
def detect_with_cascade(data, fs=4.8, model_name='GCaMP6f', verbosity=0):
    """
    使用CASCADE深度学习方法推断神经脉冲
    
    CASCADE = Calibrated Analysis of Spiking by Deep Evaluation
    
    参数
    ----
    data : np.ndarray
        神经元荧光数据（ΔF/F）
    fs : float
        采样频率（Hz）
    model_name : str
        预训练模型名称：
        - 'GCaMP6f': GCaMP6f指示剂
        - 'GCaMP6s': GCaMP6s指示剂
        - 'GCaMP8': GCaMP8指示剂（需自行训练）
    verbosity : int
        详细程度（0=静默，1=基本，2=详细）
    
    返回
    ----
    spike_prob : np.ndarray
        每个时间点的脉冲概率（0-1）
    spike_events : list
        检测到的脉冲事件
    
    依赖
    ----
    需要安装CASCADE: pip install cascade2p
    """
    try:
        from cascade2p import cascade
    except ImportError:
        raise ImportError(
            "需要安装CASCADE库。\n"
            "安装方法：pip install cascade2p\n"
            "或参考：https://github.com/HelmchenLabSoftware/Cascade"
        )
    
    # 准备数据格式（CASCADE需要2D数组：neurons x timepoints）
    data_2d = data.reshape(1, -1)
    
    # 加载预训练模型
    model = cascade.models.load_model(model_name)
    
    # 推断脉冲概率
    spike_prob = cascade.predict(model, data_2d, verbosity=verbosity)
    spike_prob = spike_prob.flatten()
    
    # 检测脉冲事件（阈值法）
    spike_threshold = 0.5  # CASCADE推荐阈值
    spike_indices = np.where(spike_prob > spike_threshold)[0]
    
    spike_events = []
    for idx in spike_indices:
        spike_events.append({
            'spike_idx': idx,
            'spike_time': idx / fs,
            'spike_probability': spike_prob[idx]
        })
    
    return {
        'spike_prob': spike_prob,
        'spike_events': spike_events,
        'method': 'CASCADE',
        'model': model_name,
        'threshold': spike_threshold
    }
```

**方案C - 简化的非负反卷积（中等难度，无外部依赖）**

```python
def simple_nonnegative_deconvolution(data, tau=1.5, fs=4.8, lambda_reg=0.1):
    """
    简化的非负稀疏反卷积
    
    基于模型：F(t) = baseline + Σ A_i * exp(-(t-t_i)/tau) + noise
    
    使用L1正则化的非负最小二乘法求解
    
    参数
    ----
    data : np.ndarray
        荧光数据
    tau : float
        衰减时间常数（秒）
    fs : float
        采样频率（Hz）
    lambda_reg : float
        L1正则化强度（控制稀疏性）
    
    返回
    ----
    spikes : np.ndarray
        推断的脉冲强度
    """
    from scipy.optimize import nnls
    from scipy.sparse import diags
    
    n = len(data)
    
    # 构建前向模型矩阵（卷积矩阵）
    # 每列代表一个脉冲在不同时间点的衰减
    decay_samples = int(tau * fs * 5)  # 5个tau的长度
    kernel = np.exp(-np.arange(decay_samples) / (tau * fs))
    
    # 构建Toeplitz矩阵
    from scipy.linalg import toeplitz
    col = np.zeros(n)
    col[:decay_samples] = kernel
    row = np.zeros(n)
    row[0] = kernel[0]
    H = toeplitz(col, row)
    
    # 添加L1正则化（通过增加虚拟方程）
    H_reg = np.vstack([H, lambda_reg * np.eye(n)])
    y_reg = np.concatenate([data, np.zeros(n)])
    
    # 非负最小二乘求解
    spikes, residual = nnls(H_reg, y_reg)
    
    # 稀疏化（去除小值）
    threshold = 0.01 * np.max(spikes)
    spikes[spikes < threshold] = 0
    
    return spikes
```

### 建议3：改进基线估计方法 ⭐⭐

**优先级**: 🟡 **P1**  
**工作量**: 4小时  
**理由**: 影响检测准确性，特别是"波谷"（抑制）检测

#### 问题描述
当前使用固定百分位数（`baseline_percentile=8`），这可能：
- 在基线漂移时估计不准
- 无法检测负向偏差（神经抑制）
- 调研报告第II节和第VII节强调基线方法的重要性

> "F0的选择直接决定了检测'波谷'的可能性。如果研究者选择使用滑动*最小值*来定义F0，那么根据定义，F(t)永远不会低于F0(t)。"  
> — 调研报告第II节

#### 改进方案

```python
def estimate_baseline(
    data, 
    method: Literal['percentile', 'spline', 'sliding_window', 'static'] = 'percentile',
    percentile: float = 8.0,
    window_size: Optional[int] = None,
    spline_smoothness: float = 0.1
) -> np.ndarray:
    """
    多种基线估计方法
    
    参数
    ----
    data : np.ndarray
        输入信号
    method : str
        基线估计方法：
        - 'percentile': 全局百分位数（当前方法，简单但可能不准确）
        - 'spline': 样条拟合（推荐，能处理漂移）
        - 'sliding_window': 滑动窗口百分位数（保留负向偏差）
        - 'static': 静态窗口（用户指定时间段）
    percentile : float
        百分位数，用于'percentile'和'sliding_window'方法
    window_size : int, optional
        滑动窗口大小（采样点数），用于'sliding_window'方法
        默认为数据长度的10%
    spline_smoothness : float
        样条平滑度，用于'spline'方法
        值越大越平滑
    
    返回
    ----
    baseline : np.ndarray or float
        估计的基线（可能是标量或时间序列）
    
    参考
    ----
    调研报告第II节："基线(F0)估计与ΔF/F标准化"
    """
    
    if method == 'percentile':
        # 当前方法：全局百分位数
        return np.percentile(data, percentile)
    
    elif method == 'spline':
        # 样条拟合基线（推荐方法）
        from scipy.interpolate import UnivariateSpline
        
        x = np.arange(len(data))
        # 首先找到低活动点作为样条节点
        low_activity_mask = data < np.percentile(data, 25)
        knots_x = x[low_activity_mask]
        knots_y = data[low_activity_mask]
        
        # 拟合样条
        # s参数控制平滑度：s=0完全拟合，s>0允许偏差
        s_param = len(data) * spline_smoothness
        spline = UnivariateSpline(knots_x, knots_y, s=s_param, k=3)
        
        baseline = spline(x)
        
        # 确保基线不超过信号
        baseline = np.minimum(baseline, data)
        
        return baseline
    
    elif method == 'sliding_window':
        # 滑动窗口百分位数（保留负向偏差的能力）
        if window_size is None:
            window_size = len(data) // 10
        
        # 确保窗口大小为奇数
        if window_size % 2 == 0:
            window_size += 1
        
        baseline = np.zeros_like(data)
        half_window = window_size // 2
        
        for i in range(len(data)):
            # 确定窗口范围
            start = max(0, i - half_window)
            end = min(len(data), i + half_window + 1)
            
            # 计算窗口内的百分位数
            window_data = data[start:end]
            baseline[i] = np.percentile(window_data, percentile)
        
        return baseline
    
    elif method == 'static':
        # 静态窗口：使用指定时间段的平均值
        # 例如：实验开始前的安静期
        # 这里假设前10%的数据是基线期
        baseline_period = int(len(data) * 0.1)
        return np.mean(data[:baseline_period])
    
    else:
        raise ValueError(f"未知的基线估计方法: {method}")


def estimate_baseline_adaptive(data, fs=4.8):
    """
    自适应选择最佳基线估计方法
    
    根据数据特性自动选择：
    - 如果基线稳定 → percentile
    - 如果基线漂移 → spline
    - 如果有周期性波动 → sliding_window
    """
    # 评估基线稳定性
    sorted_data = np.sort(data)
    lower_third = sorted_data[:len(sorted_data)//3]
    baseline_std = np.std(lower_third)
    baseline_mean = np.mean(lower_third)
    baseline_cv = baseline_std / baseline_mean if baseline_mean > 0 else float('inf')
    
    # 评估漂移
    from scipy.stats import linregress
    x = np.arange(len(data))
    slope, _, _, _, _ = linregress(x, data)
    drift_magnitude = abs(slope * len(data) / np.mean(data))
    
    # 决策逻辑
    if baseline_cv < 0.1 and drift_magnitude < 0.05:
        # 基线稳定，无明显漂移
        method = 'percentile'
    elif drift_magnitude > 0.1:
        # 明显漂移
        method = 'spline'
    else:
        # 中等变异
        method = 'sliding_window'
    
    print(f"  自适应基线估计: 选择 '{method}' 方法 "
          f"(CV={baseline_cv:.3f}, drift={drift_magnitude:.3f})")
    
    return estimate_baseline(data, method=method)
```

```python
def fit_decay_kinetics(
    decay_segment, 
    fs=4.8, 
    model: Literal['single', 'double', 'auto'] = 'auto'
):
    """
    拟合钙瞬变的衰减动力学
    
    参数
    ----
    decay_segment : np.ndarray
        从峰值到基线的衰减部分（已减去基线）
    fs : float
        采样频率
    model : str
        - 'single': 单指数 F(t) = A * exp(-t/tau)
        - 'double': 双指数 F(t) = A1 * exp(-t/tau1) + A2 * exp(-t/tau2)
        - 'auto': 自动选择（基于AIC准则）
    
    返回
    ----
    fit_result : dict
        拟合结果，包含：
        - 'model': 使用的模型
        - 'tau' 或 'tau_fast', 'tau_slow': 时间常数
        - 'amplitude' 或 'A1', 'A2': 振幅系数
        - 'r_squared': 拟合优度
        - 'fitted_curve': 拟合曲线
    """
    from scipy.optimize import curve_fit
    
    # 归一化
    if len(decay_segment) < 3 or decay_segment[0] <= 0:
        return {'model': 'none', 'tau': np.nan, 'r_squared': 0}
    
    decay_normalized = decay_segment / decay_segment[0]
    t = np.arange(len(decay_segment)) / fs
    
    # 单指数模型
    def single_exp(t, tau):
        return np.exp(-t / tau)
    
    # 双指数模型
    def double_exp(t, tau1, A1_ratio, tau2):
        A2_ratio = 1 - A1_ratio
        return A1_ratio * np.exp(-t / tau1) + A2_ratio * np.exp(-t / tau2)
    
    def compute_r_squared(y_true, y_pred):
        ss_res = np.sum((y_true - y_pred) ** 2)
        ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
        return 1 - ss_res / ss_tot if ss_tot > 0 else 0
    
    def compute_aic(n, rss, k):
        """Akaike Information Criterion"""
        return n * np.log(rss / n) + 2 * k
    
    # 拟合单指数
    try:
        # 初始猜测：tau = 使数据衰减到37%的时间
        t_37 = t[np.argmin(np.abs(decay_normalized - 0.37))] if len(t) > 0 else 1.0
        
        popt_single, _ = curve_fit(
            single_exp, t, decay_normalized,
            p0=[t_37],
            bounds=([0.1], [10.0]),  # tau在0.1到10秒之间
            maxfev=1000
        )
        tau = popt_single[0]
        
        fitted_single = single_exp(t, tau)
        r2_single = compute_r_squared(decay_normalized, fitted_single)
        rss_single = np.sum((decay_normalized - fitted_single) ** 2)
        aic_single = compute_aic(len(t), rss_single, k=1)
        
    except Exception as e:
        tau = np.nan
        r2_single = 0
        aic_single = np.inf
        fitted_single = np.zeros_like(t)
    
    # 拟合双指数
    try:
        popt_double, _ = curve_fit(
            double_exp, t, decay_normalized,
            p0=[0.2, 0.6, 1.0],  # tau_fast, A1_ratio, tau_slow
            bounds=([0.05, 0.1, 0.3], [2.0, 0.9, 10.0]),
            maxfev=2000
        )
        tau_fast, A1_ratio, tau_slow = popt_double
        
        fitted_double = double_exp(t, tau_fast, A1_ratio, tau_slow)
        r2_double = compute_r_squared(decay_normalized, fitted_double)
        rss_double = np.sum((decay_normalized - fitted_double) ** 2)
        aic_double = compute_aic(len(t), rss_double, k=3)
        
    except Exception as e:
        tau_fast = np.nan
        tau_slow = np.nan
        A1_ratio = np.nan
        r2_double = 0
        aic_double = np.inf
        fitted_double = np.zeros_like(t)
    
    # 模型选择
    if model == 'single':
        return {
            'model': 'single_exponential',
            'tau': tau,
            'amplitude': decay_segment[0],
            'r_squared': r2_single,
            'fitted_curve': fitted_single * decay_segment[0],
            'aic': aic_single
        }
    
    elif model == 'double':
        return {
            'model': 'double_exponential',
            'tau_fast': tau_fast,
            'tau_slow': tau_slow,
            'A1_ratio': A1_ratio,
            'A2_ratio': 1 - A1_ratio,
            'amplitude': decay_segment[0],
            'r_squared': r2_double,
            'fitted_curve': fitted_double * decay_segment[0],
            'aic': aic_double
        }
    
    elif model == 'auto':
        # 使用AIC选择最佳模型
        if aic_double < aic_single - 2:  # AIC差异>2认为显著
            selected_model = 'double_exponential'
            result = {
                'model': selected_model,
                'tau_fast': tau_fast,
```
