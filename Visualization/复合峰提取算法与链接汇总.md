# 复合峰提取算法与资源总览

## 执行摘要
- 本综述基于《调研_复合峰检测.md》系统梳理复合峰（重叠峰）识别与提取的主要技术路线与权威资源链接，涵盖模型无关、模型相关、迭代反卷积、神经科学专用反卷积、数据驱动与事件型时空分析、统计爆发检测等。
- 面向钙成像轨迹的复合峰解析，推荐的落地路径为：实时与可解释性优先时采用 OASIS/CaImAn；追求高召回与复杂爆发解析时引入 CASCADE；存在空间重叠/污染时采用 DeepCINAC；面向星形胶质等传播事件时用 AQuA/AstroCaST。

## 方法分类与链接

### 模型无关方法（识别/增强）
- 二阶导数 + Savitzky–Golay 导数：在平滑后计算二阶导数以放大负谷，识别肩峰与重叠峰。
  - Spectrify 导数综述与 S-G 导数说明: https://docs.spectrify.app/preprocessing/derivative
  - OriginLab 二阶导数寻峰算法: https://www.originlab.com/doc/Origin-Help/PA-Algorithm
  - Raman 二阶导数与基线校正应用: https://opg.optica.org/abstract.cfm?uri=osac-4-9-2468
  - Savitzky–Golay 维基: https://en.wikipedia.org/wiki/Savitzky%E2%80%93Golay_filter
  - MATLAB S-G 滤波器设计示例: https://www.mathworks.com/help/signal/ug/design-and-analysis-of-savitzky-golay-filters.html
- 傅里叶自去卷积（FSD）：在频域锐化谱带宽以提升分辨率（高 S/N 数据）。
  - SPIE 会议论文: https://www.spiedigitallibrary.org/conference-proceedings-of-spie/289/0000/Resolution-Of-Complex-Band-Contours-By-Means-Of-Fourier-Self/10.1117/12.932187.full
  - Optica 综述: https://opg.optica.org/abstract.cfm?uri=as-35-3-271
  - 蛋白二级结构解析（ResearchGate）: https://www.researchgate.net/publication/249337008_Protein_Conformation_by_Infrared_Spectroscopy_Resolution_Enhancement_by_Fourier_Self-Deconvolution
  - OriginLab FSD 工具: https://www.originlab.com/fileExchange/details.aspx?fid=309
- 小波变换（WT）：多尺度细节系数过零点检测峰，跨尺度一致性抑制噪声。
  - NI 小波峰检测指南: https://www.ni.com/en/support/documentation/supplemental/06/wavelet-based-peak-detection.html
  - XRD 小波检测论文: https://core.ac.uk/download/pdf/304661029.pdf

### 模型相关方法（拟合/复合模型）
- 非线性最小二乘（NLSQ）复合拟合：以高斯/洛伦兹/Voigt/EMG 等函数叠加建模，联合背景拟合多峰参数。
  - lmfit 文档总览: https://lmfit.github.io/lmfit-py/contents.html
  - 内置峰形模型: https://lmfit.github.io/lmfit-py/builtin_models.html
  - Python 多峰拟合示例: https://stackoverflow.com/questions/46684859/fitting-a-multi-peak-function-to-a-dataset-using-lmfit
  - Voigt 拟合讨论: https://scicomp.stackexchange.com/questions/40751/fitting-data-with-a-voigt-function
  - 近似 Voigt 函数（LIBS）: https://opg.optica.org/abstract.cfm?uri=ao-60-14-4120
  - OriginLab 多峰拟合工具与手册: https://www.originlab.com/doc/Origin-Help/Fit-MultiPeakFit-Tool, https://www.originlab.com/pdfs/PFM_Manual.PDF
  - MATLAB peakfit.m（44 种峰形）: https://www.mathworks.com/matlabcentral/fileexchange/23611-peakfit-m
- 几何法（垂线/切线/三角）：快速近似分割重叠峰，现代分析中多用于粗初值。
  - 色谱重叠峰处理专利: https://patents.google.com/patent/CN111337606B/zh

### 迭代反卷积（恢复/解析）
- Jansson 方法：引入非负与上界约束的迭代反卷积，鲁棒且无需峰数先验。
  - 方法评估论文（PMC）: https://pmc.ncbi.nlm.nih.gov/articles/PMC5181942/
- Richardson–Lucy（RL）：针对泊松噪声最优的最大似然迭代反卷积。
  - 维基百科: https://en.wikipedia.org/wiki/Richardson%E2%80%93Lucy_deconvolution
  - scikit‑image 示例: https://scikit-image.org/docs/0.25.x/auto_examples/filters/plot_deconvolution.html
  - RL 与泊松统计（Optica）: https://opg.optica.org/josaa/abstract.cfm?uri=josaa-12-1-58
  - 应用综述（PMC）: https://pmc.ncbi.nlm.nih.gov/articles/PMC3986040/
- Landweber 迭代：以迭代次数作为正则化参数的经典反问题方法。
  - 维基百科: https://en.wikipedia.org/wiki/Landweber_iteration
  - 多级阈值加速（MLTL）: https://bigwww.epfl.ch/algorithms/mltldeconvolution/

### 神经科学专用反卷积（钙轨迹脉冲推断）
- OASIS / CaImAn：稀疏非负反卷积，自动将宽峰分解为脉冲序列（AR(p) 支持上升/衰减动力学）。
  - PLOS 论文（OASIS）: https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005423
  - OASIS GitHub: https://github.com/j-friedrich/OASIS
  - CaImAn 文档与仓库: https://caiman.readthedocs.io, https://github.com/flatironinstitute/CaImAn

### 数据驱动方法（辅助/替代）
- PCA 与盲源分离：在多样本矩阵中分离组分，辅助初值与伪迹识别。
  - 综述与教材: https://pmc.ncbi.nlm.nih.gov/articles/PMC4792409/, https://www.utdallas.edu/~herve/abdi-awPCA2010.pdf, https://en.wikipedia.org/wiki/Principal_component_analysis
  - 细胞去卷积综述（NAR）: https://academic.oup.com/nar/article/52/9/4761/7645775
- 聚类 GMM + NLSQ：用 GMM 提供中心/宽度/权重作为复合拟合初始值。
  - 方法介绍: https://medium.com/@kwakyenimo/peak-deconvolution-with-the-help-of-machine-learning-b6a19bed798a
- 深度学习（时间/空间重叠）
  - CASCADE（脉冲推断与噪声匹配）: https://github.com/HelmchenLabSoftware/Cascade, https://colab.research.google.com/github/HelmchenLabSoftware/Cascade/blob/master/Demo%20scripts/Calibrated_spike_inference_with_Cascade.ipynb, https://gcamp6f.com/
  - DeepCINAC（影片级时空判别）: https://eneuro.org/content/7/4/ENEURO.0038-20.2020, https://gitlab.com/cossartlab/deepcinac, https://pmc.ncbi.nlm.nih.gov/articles/PMC7438055
  - DeepCAD（自监督去噪增强）: https://github.com/cabooster/DeepCAD

### 事件型时空分析（传播事件/ROI 之外）
- AQuA：基于事件的动态流形检测与追踪，区分空间上独立起源的事件。
  - GitHub 与综述: https://github.com/yu-lab-vt/AQuA, https://pmc.ncbi.nlm.nih.gov/articles/PMC6697228/
- AstroCaST：星形胶质钙事件工具包，适合长时程复杂形态事件。
  - 论文与资源: https://pmc.ncbi.nlm.nih.gov/articles/PMC11179567/, https://www.frontiersin.org/articles/10.3389/fncel.2024.1380688/full

### 统计爆发检测（边界稳健定义）
- NeuroDSP 双阈值爆发检测：核心与延伸边界双阈值，精确定义复合峰持续时间。
  - 文档与仓库: https://neurodsp-tools.github.io/neurodsp/burst.html, https://github.com/neurodsp-tools/neurodsp
- Elephant Kleinberg 爆发检测：将事件序列建模为自动机识别频率突增区间。
  - 工具与文档: https://elephant.readthedocs.io, https://ebrains.eu/tools/elephant

## 实施建议（面向钙轨迹）
- 即刻替换启发式：在 `element_extraction.py` 的复合峰检测中用 OASIS 反卷积替代 `find_peaks` 主路径，通过 L1 正则与 AR(2) 核自然拆分宽峰。
- 精度升级：集成 CASCADE 的脉冲概率输出作为事件时间列，复合峰内的子事件由概率峰识别；对空间重叠数据并行引入 DeepCINAC。
- 特殊场景：星形胶质或传播性事件采用 AQuA/AstroCaST 的事件型分析，避免将传播波形误解为复合峰。
