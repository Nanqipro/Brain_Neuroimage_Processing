# **神经-行为动态关联分析技术文档**

## **基于马尔可夫模型 (Markov Model) 的分析流程详解**

### **1\. 概述**

本文档旨在详细说明 behavioral\_markov\_analysis.py 脚本的分析流程。该分析的核心目的是将**微观的神经元钙爆活动**（离散事件）与**宏观的小鼠行为**（连续状态）在时间轴上对齐，并通过马尔可夫模型揭示神经群体状态的动态转移规律。

### **2\. 分析步骤详解**

#### **步骤一：数据加载与预处理**

**目的**：将原始数据读入内存，并建立基本的索引映射。

* **输入 (Input)**：  
  1. EMtrace01.xlsx \- Sheet1.csv (Trace文件)：包含每帧的时间戳、所有神经元的荧光值（n1, n2...）、以及人工标注的行为标签（behavior）。  
  2. amplitude\_duration\_clusters.csv (Cluster文件)：包含从Trace中提取出的离散“钙爆”事件，每个事件有开始时间(start\_idx)、结束时间(end\_idx)、所属神经元(neuron)以及该钙爆的聚类标签(cluster\_label)。  
* **操作 (Process)**：  
  * 加载两个CSV文件为 Pandas DataFrame。  
  * 提取所有唯一的 cluster\_label（如 'Cluster 1', 'Cluster 2'），并建立映射字典（如 {'Cluster 1': 1, 'Cluster 2': 2}），其中 0 被保留表示“静息态/无钙爆”。  
  * 识别 Trace 文件中所有以 'n' 开头的神经元列。  
* **输出 (Output)**：  
  * df\_trace: 包含原始荧光和行为数据的表。  
  * cluster\_map: 状态编码字典。  
  * n\_frames: 总时间帧数。

#### **步骤二：构建逐帧神经元状态矩阵 (Neural State Matrix)**

**目的**：解决“时间不对齐”问题。将离散的钙爆事件（Event-based）映射回连续的时间帧（Frame-based），通过“光栅化”将每个神经元在每一帧的状态数字化。

* **输入 (Input)**：  
  * Trace文件的总帧数。  
  * Cluster文件中的事件列表（包含 start\_idx, end\_idx, neuron, cluster\_label）。  
* **操作 (Process)**：  
  * 初始化一个全零矩阵 Matrix，形状为 \[总帧数 x 神经元数量\]。默认值 0 代表神经元在当前帧处于静息状态。  
  * 遍历 Cluster 文件中的每一行（每一个钙爆事件）：  
    * 找到对应的神经元列索引。  
    * 找到对应的 start\_idx 到 end\_idx 时间段。  
    * 将该时间段内矩阵对应位置的值，修改为该钙爆的 cluster\_code（如 1 或 2）。  
* **输出 (Output)**：  
  * neural\_state\_matrix: 一个巨大的二维整数矩阵。  
  * **示例**：matrix\[100, 5\] \= 2 表示“在第100帧，第5号神经元正在发生属于 Type 2 的钙爆”。  
* **结果/发现**：  
  * 这就把复杂的原始荧光值（连续浮点数）转化为了可解释的**离散状态序列**。

#### **步骤三：定义“群体网络状态” (Population States)**

**目的**：降维。单个神经元的状态（如n1在爆发，n2在静息）组合太多，无法直接分析。我们需要定义“全脑在这个瞬间处于什么模式”。

* **输入 (Input)**：  
  * neural\_state\_matrix (上一步的输出)。  
* **操作 (Process)**：  
  1. **特征提取**：对于每一帧 t，统计当前有多少个神经元处于 Cluster 1，多少个处于 Cluster 2... 形成一个特征向量 \[Count\_C1, Count\_C2, ...\].  
  2. **聚类 (K-Means)**：将所有帧（例如3000帧）看作3000个样本，利用 K-Means 算法将它们聚类为 K 个（代码中设为6）典型的“网络模态”。  
* **输出 (Output)**：  
  * Network\_State: 为 Trace 文件新增的一列数据。每一帧都被标记为 0 到 5 中的一个数字。  
* **结果/发现**：  
  * **发现神经网络的“模态” (Motifs)**：例如，State 0 可能是“全脑静默”，State 3 可能是“特定一组神经元同步爆发”。这是从数据中自动涌现出的全局模式。

#### **步骤四：关联行为数据 (Emission Analysis)**

**目的**：赋予网络状态生物学意义。回答“当大脑处于这种状态时，小鼠在干什么？”

* **输入 (Input)**：  
  * Network\_State 列（计算出的神经状态）。  
  * behavior 列（原始记录的行为标签）。  
* **操作 (Process)**：  
  * 构建混淆矩阵（Crosstab），计算联合分布。  
  * **归一化计算发射概率**：$P(Behavior | Network\\\_State) \= \\frac{该状态下发生该行为的次数}{该状态出现的总次数}$。  
* **输出 (Output)**：  
  * emission\_prob: 发射概率矩阵。  
  * state\_dominant\_behavior: 每个网络状态对应的“优势行为”（概率最大的行为）。  
* **结果/发现**：  
  * **神经-行为解码**：如果发现 State 2 对应 "Open-arm" 的概率高达 80%，则 State 2 可以被定义为“焦虑/探索相关神经态”。如果某个状态对应的行为很杂乱，说明该神经活动模式可能与当前定义的行为无关。

#### **步骤五：构建马尔可夫转移矩阵 (Transition Matrix)**

**目的**：分析大脑状态的动态切换规律。

* **输入 (Input)**：  
  * 时间序列上的 Network\_State 列表：\[S\_0, S\_0, S\_1, S\_2, S\_2, ...\]  
* **操作 (Process)**：  
  * 统计所有 $S\_t \\to S\_{t+1}$ 的跳转次数。  
  * 归一化，使得每一行的概率之和为 1。  
* **输出 (Output)**：  
  * transition\_matrix: $N \\times N$ 的矩阵，第 $i$ 行 $j$ 列的值代表从 State $i$ 转移到 State $j$ 的概率。  
* **结果/发现**：  
  * **预测与路径分析**：可以发现状态流转的“高速公路”。例如，发现小鼠总是遵循 静息态 \-\> 预备态(State X) \-\> 行为态(State Y) 的路径，这揭示了神经计算的时间结构。

#### **步骤六：可视化 (Visualization)**

**目的**：直观展示模型结果。

* **输入 (Input)**：  
  * 转移矩阵、发射概率、优势行为标签。  
* **操作 (Process)**：  
  1. **状态转移图 (Network Graph)**：使用 NetworkX 库。  
     * **节点**：代表 6 种网络状态。颜色代表该状态下的主导行为。  
     * **边**：代表状态间的转移概率。线条越粗，概率越大。  
  2. **热图 (Heatmap)**：使用 Seaborn 库展示发射概率矩阵。  
* **输出 (Output)**：  
  * markov\_model\_plot.png: 一张展示大脑如何在不同行为模式对应的神经状态间切换的网络图。  
  * emission\_probability.png: 展示神经状态与行为对应强度的热图。

### **3\. 总结**

这个流程实现了一个完整的**从底向上 (Bottom-up)** 的分析：

1. **Micro**: 神经元钙爆特征 (Cluster)  
2. **Meso**: 逐帧神经元状态 (State Matrix)  
3. **Macro**: 全脑网络模态 (Population States)  
4. **Behavior**: 行为关联与动态预测 (Markov Model)

通过此分析，你可以回答：“小鼠在进入开臂（Open-arm）之前，大脑通常会先经历哪种特定的神经活动模式？”这对于理解神经编码机制至关重要。
